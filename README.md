# Open Text Collections #7
## Kilmeri texts

This collection features 71 texts from the Kilmeri language, spoken in Papua New Guinea.

The texts were narrated by Usi Kul, Margaret Osi, Brigitte Esau, Susam Bisam, and Andrew Wapi  and compiled by Claudia Gersnter-Link

The files in this repository contain the texts in the CLDF format. A human readable version of
the book is available under the name "Clans, spirits, land and food: Kilmeri texts" at https://zenodo.org/records/17702074
